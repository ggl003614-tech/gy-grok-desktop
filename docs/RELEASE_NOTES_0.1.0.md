# Grok Desk 0.1.0

This is the first Windows community-preview release of Grok Desk, a local desktop
GUI for the official Grok Build CLI.

Highlights include subscription-aware login, capability-driven model and
reasoning controls, streaming ACP tasks and permissions, recoverable sessions,
project files/search, Git Diff review, a complete embedded Grok TUI, themes,
shortcuts, diagnostics, and Windows EXE/MSI/NSIS packages.

Requirements: Windows 10/11 x64, WebView2 Runtime, a locally installed Grok Build
CLI, and a Grok/X account entitled to use Grok Build.

The files in this preview are **not code signed**. Windows may display a
SmartScreen warning. Download only from this repository's Release page and verify
the published SHA-256 checksums before running.

Grok Desk is independent community software and is not affiliated with or
endorsed by xAI or X.
